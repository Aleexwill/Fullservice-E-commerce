# Demo de fondos animados

Ruta de preview: `/demo-fondos`

Incluye cuatro variantes visuales para la web pública:

1. Aurora / luces difusas.
2. Malla técnica.
3. Malla técnica + aurora.
4. Profundidad industrial con capas geométricas.

La pantalla permite cambiar entre intensidad suave, media e intensa y activar u ocultar la malla. La animación respeta `prefers-reduced-motion`.
